# Job Board Platform

A web-based recruitment system for a single organization to publish its own job openings and manage incoming applications in one centralized place.

---

## What it does

- Displays active job vacancies on a public portal.
- Allows filtering by location and department.
- Candidates can apply without creating an account (just fill out a form and upload their CV).
- Administrators can:
  - Create, edit, and deactivate vacancies.
  - Review applications.
  - Update application statuses.
  - View status history.
- Sends email notifications to candidates.

---

## Tech stack

- **Frontend:** React + TypeScript
- **Backend:** Node.js + TypeScript + Express
- **Database:** PostgreSQL + Prisma
